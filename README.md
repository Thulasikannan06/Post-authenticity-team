# Public Signature Poll System
## Description
The Public Signature Poll System is a simple web application that allows users to register, log in, create posts with an image, title, and description, and create a public signature poll. Users can support a poll, and when it reaches 10 supports, the poll status automatically changes to **Active**.
## Features
- User Registration
- User Login
- Home Feed
- Create Post
- Upload Image
- Create Public Signature Poll
- Support Button
- Support Counter
- Automatic Activation after 10 Supports
## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage
## Project Flow
1. Register a new account.
2. Login using the registered email and password.
3. Create a new post with an image, title, and description.
4. Create a Public Signature Poll.
5. Users can support the poll.
6. When the support count reaches 10, the poll status automatically changes to **Active**.
